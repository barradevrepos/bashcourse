# Bash Programming Course

Welcome to the Bash Programming Course.

This repository contains a progressive introduction to Bash scripting, focused on understanding how Bash interacts with the GNU/Linux operating system and how system tools can be combined to automate tasks.

The course is organized into lessons. Each lesson introduces new concepts through explanations, command-line examples, scripts, and practical activities.

## Lessons

- [Lesson 01](Lesson%2001/)

  Introduction to Bash, command execution, scripts, environment variables, output redirection, standard output, standard error, and introductory practical exercises.

Start with **Lesson 01** and follow the material in order.
